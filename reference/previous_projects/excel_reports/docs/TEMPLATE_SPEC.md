# Excelテンプレート仕様 `__report__`

**対象:** 統合版 v1.0.0（Python 3.12 / openpyxl）

テンプレートは `.xlsx` とし、**設定シート`__report__`と、1つ以上の出力シート**を作成します。`ReportGenerator.template(records, template_path)`で読み込み、完成ブックから`__report__`を削除します。

## 1. 設定シートのセル配置

### 1.1 B1/B2（帳票全体で共通）

| セル | 内容 | 例 |
|---|---|---|
| A1 | 説明ラベル | `sort_field` |
| B1 | Itemのソートフィールド。空欄ならソートなし | 空欄、`order` |
| A2 | 説明ラベル | `descending` |
| B2 | Excelの真偽値。ソート指定がなくても必須 | `FALSE` |

**注意**：`B2`へ文字列の`"FALSE"`を書かず、Excelの論理値`FALSE`を設定してください。

### 1.2 A4:E4の見出し、A5:E... の抽出条件

| 列 | 意味 | 例 |
|---|---|---|
| A `sheet` | 対象シート名 | `温度一覧` |
| B `logic` | 同一シートの条件全体を結ぶ演算子 | `AND`、`OR` |
| C `field` | 比較するフィールド | `record.department`、`item.kind`、`kind` |
| D `operator` | 比較演算子 | `==`、`!=`、`<`、`<=`、`>`、`>=` |
| E `value` | 比較値（Excelセルの型を保持） | `製造課`、数値 `10` |

各行は1条件です。シート名が同じ行は同じ`logic`を指定してください。`field`に接頭辞がない場合は**旧仕様に従ってItemフィールド**として解釈します。

例：

| sheet | logic | field | operator | value |
|---|---|---|---|---|
| 温度一覧 | AND | record.department | == | 製造課 |
| 温度一覧 | AND | item.temperature | >= | 10 |
| 電圧一覧 | OR | record.equipment | == | 設備D |
| 電圧一覧 | OR | item.voltage | >= | 100 |

**評価仕様**：ANDでは全Record条件が成立し、Item条件があれば1件の同じItemが全Item条件を満たす必要があります。ORではRecord条件のどれか、またはItem条件のどれかが成立すれば採用します。`items=[]`の場合はRecord条件での採否のみが可能です。詳しくは[DESIGN.md](DESIGN.md)。

### 1.3 G4:J4の見出し、G5:J... のItem配置

| 列 | 意味 | 例 |
|---|---|---|
| G `sheet` | 出力先シート | `温度一覧` |
| H `position` | Itemの表示位置。1始まり・連番 | `1`、`2` |
| I `title` | Excelに表示する列グループ名 | `初回` |
| J `key` | Item.titleと照合するキー | `初期測定` |

例：

| sheet | position | title | key |
|---|---:|---|---|
| 温度一覧 | 1 | 初期測定 | 初期測定 |
| 温度一覧 | 2 | 中間測定 | 中間測定 |
| 温度一覧 | 3 | 最終測定 | 最終測定 |
| 電圧一覧 | 1 | 初回 | 初期測定 |
| 電圧一覧 | 2 | 最終回 | 最終測定 |

- **キーの完全一致**で位置を決定します。例：Itemが`初期測定`と`最終測定`だけなら、温度一覧の`中間測定`は空欄。電圧一覧はそもそも2枠だけです。
- J列が**空欄**ならI列の表示名をキーに使用します（旧テンプレート互換）。
- 同じシートの`position`は1から連番、キーは重複禁止。表示名の重複は許容します。
- このシートに定義されていないキーを持つItemは、**そのシートの出力値から除外**します。抽出条件ではそのItemも評価されます。
- 行の順序に関係なくH列で順番が決まります。Itemのソート指定がなくても正しい列へ出力します。

### 1.4 K列以降について

**この配布版の`load_template()`が読むのはA:EとG:J、B1/B2、および出力シート内のマーカーです。** `__report__!K:P`の独自設定を読む機能は実装されていません。既存の社内GitHub版にその機能がある場合は、独自実装として差分マージが必要です。J列へのキー追加はK列以降を物理的に右へ挿入する必要がないので、空欄のJ列に値を入れる方法を推奨します。

## 2. 出力シートに置くマーカー

マーカーはセルの文字列に**完全一致**させます。

| マーカー | 用途 | 制約 |
|---|---|---|
| `{{header:department}}` | Recordから上部の共通値を1回出力 | Item見出しより上の行 |
| `{{record:record_id}}` | Recordの1フィールドを一覧へ出力 | Itemと同じ見本行、Item列の左側 |
| `{{item:voltage}}` | 1 Itemの1フィールドを一覧へ出力 | 同じ見本行に連続した列で配置 |
| `{{item_title}}` | 見出しの上段グループ名を設定 | Item見本の左端、見本行より上。1シートに1つ |

`header`マーカーは複数箇所に同じフィールドを置けますが、値は同じです。テンプレート内の任意文字列や注記は基本的にそのまま残ります。

最小例（Itemが1フィールド、見本行が7行目）：

| 行／列 | A | B | C |
|---|---|---|---|
| 3 | 担当部署 | `{{header:department}}` | |
| 5 | 管理番号 | | `{{item_title}}` |
| 6 | | | 電圧 |
| 7 | `{{record:record_id}}` | （他Record列があれば） | `{{item:voltage}}` |

**RecordとItemのマーカーは同じ見本行**に必要です。Itemのマーカーは連続列に置き、ItemタイトルのセルはItem見本の左端に置きます。上段見出しと下段見出しの構成・書式はExcel側で決められます。Itemブロックの内部で完結する結合のみ複製対象です。

## 3. テンプレート展開で維持するもの／対象外

| 対応 | 内容 |
|---|---|
| 対応 | セル値、フォント、塗り、罫線、配置、表示形式、保護情報のコピー |
| 対応 | Item見本ブロックの横方向コピー、Record見本行の下方向コピー |
| 対応 | Itemブロック内で完結する結合、Record見本行内の結合、列幅・行高の基本的な複製 |
| 対応 | 元テンプレートにある数式の複製（同じ式文字列をコピー） |
| 非対応 | 複製対象の周辺セルを右や下へ押し出すこと |
| 非対応 | 数式中のセル参照を複製先に合わせて自動変換すること |
| 非対応 | グラフ・画像・Excelテーブル・印刷範囲・改ページ等の完全な複製や自動拡張 |

Itemブロック右側とRecord見本行より下は**書き込み先を空欄に**してください。値のあるセルまたは既存結合が重なる場合はエラーを出します。書式のみ設定された空セルは許可されます。

## 4. 左端の連番（`ROW()`）

Recordの見本行が7行目なら、A7へ次を入れる例があります。

```excel
=ROW()-6
```

ただし、Recordが0件でも見本行は残るため、この式だと見本行に「1」が表示されます。**B列にRecord IDが出るレイアウトなら、以下を推奨します**。

```excel
=IF(INDEX(B:B,ROW())="","",ROW()-6)
```

現在行のB列が空白なら番号を表示しません。見本行が7行目以外なら`6`を「最初のデータ行 - 1」に変更してください。

v1.0.0では、**テンプレート由来の数式**が見本行の下へのコピーで文字列化されないよう`excel.py`を修正しています。一方、業務データの値が`=SUM(...)`などで始まる場合は文字列として書き込み、数式として実行しないようにしています。

**重要**：見本行から下方向へコピーした際、式は**同じ文字列のまま**複製されます。`=IF(B7="","",ROW()-6)`では8行目でもB7を参照するため、上の`INDEX(B:B,ROW())`のような行依存式を使ってください。Pythonの`openpyxl`は数式を計算しないので、Excelで開いて再計算したときに表示されます。

## 5. 外部リンク警告の扱い

`ReportGenerator.template()`は`openpyxl.load_workbook(path, keep_links=False)`で読み取ります。この指定は**外部ブックリンクの引き継ぎ抑制**であり、すべての外部データ接続や名前定義・Excelの警告を消す保証ではありません。

元テンプレートをExcelで開き、必要に応じて「データ → ブックのリンク」「クエリと接続」「数式 → 名前の管理」から外部参照を調べてください。警告を消すためにOfficeの保護設定を無効化することは推奨しません。

## 6. 雛形の作り方と受入確認

1. `python example.py`で雛形を生成し、**別名**で複製する（`example.py`の再実行で上書きされるため）。
2. `__report__`のA:EでRecord条件・Item条件、G:JでItem見出しとキーを設定。
3. 出力シートに必要な`{{...}}`マーカーを配置。拡張方向のセルは空ける。
4. `ReportGenerator.template(records, copied_template)`を実行し、**雛形とは別ファイル**に保存。
5. Excelで完成ファイルを開き、異なるItem種類数・Item無し・Record無し・複数Record・連番式・印刷を確認。

**Excelにエラーなく出力できても、帳票上の業務上の意味（キー・条件・表示単位）が正しいかは別途検証が必要です。**
