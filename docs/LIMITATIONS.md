# 実装の範囲と未解決事項

この配布物は、汎用I/Oと合成業務例を接続して実行・テストできる状態です。以下を実装済みとは扱わないでください。

- 実業務のSettings・Presets・加工解析アルゴリズム、V4/V5/V6の変換、旧独自テキスト・拡張CSVの実仕様は含みません。社内情報を推測して実装していません。
- 保存はファイル単位のロックと原子的置換です。複数ファイルの更新を一括確定するトランザクション、電源断後の一式の復旧は実装していません。
- JSONL追記は全件書換えを避ける方式です。追記途中のプロセス停止や電源断で末尾が壊れる可能性があります。自動修復を実装していません。
- 編集権と強制引継ぎはこの規約を使うプログラム同士の制御です。実際のSMB・Linux端末の接続検証は未実施です。[共有編集権](SHARED_EDITING.md)の導入条件と実機確認事項を参照してください。
- 版変換付きYAMLは存続キーのコメント・配置を再利用しますが、改名キーのコメント対応や配列要素のコメント移植は行いません。テンプレートから不足値を補わず、既定値はcastで用意します。
- 実DB接続・実画面・「外部情報を更新」ボタンは未接続です。保存済み情報を外部へ再反映するサービスと合成の集約JSON例があります。
- すべての任意モデルについて、代入で壊れた値を保存前に完全再検証する保証はありません。Pydanticの代入検証など、各業務モデルに必要な方針を決めてください。
- 元Excelプロジェクトの追加report_patterns・PrintHeader拡張は、手元の元エンジンと整合していない部分があり、現構成への対応完了とはしていません。元コード・テスト・説明はreferenceへすべて収録しました。統合済みエンジンとコード方式・テンプレート方式の例は別途検証しています。
- 未提示のテキスト/2表CSVは架空仕様の接続例です。実ファイルへの適合・チャンネル規則は利用側で差し替えます。
- 管理情報は通常終了時に削除しますが、異常終了では残ります。確認後に明示引継ぎし、時間経過だけで解除しません。
- GitHubへのpush・リポジトリ作成は行いません。公開ライセンスは未設定です。

変更の大きい未確定仕様を今回のフォルダ整理に混ぜず、現在動く構成と残る判断を区別しています。
